## Bubbles-Supermarket-UI-Design

A fully designed and interactive prototype for Bubbles Kidz Supermarket, a family-owned neighborhood supermarket located 
in Santa Maria, Accra, Ghana. Designed using Figma.

## Live Prototype

👉 [View Figma Prototype](https://www.figma.com/proto/Tot0y6ZwEV1PKLG7KOpXJd/Bubbles-Supermarket-Website-Layout?node-id=0-1&t=EJSojxl1KBwIbDha-1)

## Project Overview

This project is a UI/UX design commisioned by Bubbles Kidz 
Supermarket. The goal was to create a clean, modern and 
user-friendly website experience that reflects the warm and 
community-focused nature of the store.

---

## Pages Designed

| Page | Description |
|------|-------------|
| Home | Landing page with header, navigation bar and into page/products |
| Products | Product listings with add to cart mocking functionality |
| Cart | Shopping cart with order summary |
| Checkout | Order confirmation with social media links |
| About Us | Brand story and store information |
|FAQs | Frequently asked questions |



## Features

- Fully interactive prototype with page navigation
- Add to cart notification
- Checkout confirmation page
- Responsive and clean layout
- Consistent branding and color scheme of black, orange, white and green throughout
